# 英语学习教练

一个手机优先的静态英语学习网页，面向职场英语零基础学习者。课程采用“听力输入 → 看文本 → 重点词 → 跟读 → 复述 → 工作迁移 → 本地检验”的流程。

## 当前内容

- 预置 14 天原创基础职场英语课程
- 每天约 30 分钟，可按状态缩短为 10 分钟
- 浏览器朗读示范
- 分级短句朗读，避免一开始直接读长句
- 每课填空检验
- 每课基础语音检验（不调用 AI）
- 每日任务、打卡、课程进度和复习记录
- 使用浏览器 localStorage 保存学习进度
- 支持 PWA，可添加到手机主屏幕

## GitHub Pages 部署

1. 将这些文件上传到 GitHub 仓库的 `main` 分支根目录。
2. 进入仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 `main` 分支和 `/ (root)`，点击保存。
5. 等待 GitHub Pages 生成网址后，用手机打开即可。

这是纯静态网页，不需要 Node.js、数据库或 API Key。语音识别功能取决于手机浏览器：支持时点击“开始朗读”；不支持时可以点击“我已经读过了”手动记录。

## 本地预览

在项目目录运行：

```bash
python3 -m http.server 3000
```

然后打开 `http://localhost:3000`。PWA 和语音识别通常需要 HTTPS 或 localhost 环境。

## 内容说明

网页使用原创讲解、练习和工作场景迁移，不复制《新概念英语》的完整课文或音频。学习者可以配合自己拥有的正版教材和音频，按对应课程位置学习。
